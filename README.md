# Ποδηλασία στα Ιωάννινα — δοκιμαστική έκδοση 0.1

Ανοίξτε `index.html` σε browser για δοκιμή (οι φόρμες και το ιστορικό λειτουργούν τοπικά). Για εγκατάσταση ως PWA, απαιτείται εξυπηρέτηση μέσω HTTPS ή localhost και κατάλληλη υποστήριξη του browser.

**ΠΡΟΣΟΧΗ:** Το PIN `1346` είναι ΑΠΟΚΛΕΙΣΤΙΚΑ για παρουσίαση. Ο έλεγχος γίνεται στον browser. Ούτε οι ρόλοι ούτε τα δεδομένα προστατεύονται πραγματικά. Μην δημοσιεύσετε ως παραγωγική εφαρμογή και μην αποθηκεύετε ευαίσθητες ή πραγματικές ιδιωτικές παρατηρήσεις πριν συνδεθεί ασφαλές backend.

Τα στοιχεία τηρούνται μόνο στο localStorage του συγκεκριμένου browser. Δεν συγχρονίζονται μεταξύ χρηστών. Η δήλωση συμμετοχής δεν υποστηρίζει ακόμα ακύρωση. Για την πραγματική έκδοση απαιτούνται κοινή βάση, ασφαλής server-side αυθεντικοποίηση, πολιτικές πρόσβασης και μηχανισμός επιβεβαίωσης/ακύρωσης συμμετοχών.

## Δοκιμή
1. Ανοίξτε `index.html`.
2. Από το μενού συνδεθείτε ως Admin με το **demo PIN 1346**.
3. Προσθέστε ποδηλάτες και δημιουργήστε μια βόλτα.
4. Αποσυνδεθείτε, δηλώστε συμμετοχή με όνομα.
5. Συνδεθείτε ξανά, ολοκληρώστε τη βόλτα με απόσταση και κοινή μέση ταχύτητα.

## Επόμενη παραγωγική φάση
Ασφαλές backend (π.χ. Supabase με server-side PIN validation και RLS), συγχρονισμός, κωδικοί ακύρωσης συμμετοχής, ενισχυμένο PWA icon PNG, διαχείριση αλλαγών/επεξεργασίας και εξαγωγή αντιγράφων ασφαλείας.

## Δημοσίευση στο GitHub Pages
Ανεβάστε τα αρχεία του φακέλου στη ρίζα του repository (ή στο επιλεγμένο publishing folder) και ενεργοποιήστε Settings → Pages → Deploy from a branch. Η εφαρμογή ανοίγει από GitHub Pages, αλλά αυτή η έκδοση παραμένει μόνο δοκιμαστική: τα δεδομένα αποθηκεύονται τοπικά ανά browser και το PIN 1346 είναι ορατό στον κώδικα, όχι πραγματική προστασία. Μην καταχωρίζετε πραγματικά ιδιωτικά δεδομένα μέχρι να συνδεθεί backend με ασφαλή έλεγχο πρόσβασης.
